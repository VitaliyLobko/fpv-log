# FPV Log — дрони, склад, батареї

Вебзастосунок (PWA) для телефона й комп'ютера: з чого зібрані дрони й наземка, версії прошивок,
покупки, склад деталей і розхідників, батареї. Працює без інтернету, дані синхронізуються через ваш
Google Диск. Інфраструктура (база, синхронізація, теми, «Що нового») — з
[Shooter’s Log](https://github.com/VitaliyLobko/shooting-log).

**Відкрити:** https://vitaliylobko.github.io/fpv-log/

Інтерфейс — українською або російською, тема — авто, темна, світла, нічна чи «фосфор» (**⚙**).

## Встановлення

1. Відкрити посилання: Android — у Chrome, iPhone — у Safari.
2. Android: меню ⋮ → «Установити застосунок». iPhone: «Поділитися» → «На початковий екран».
3. **⚙ → Google Диск → Підключити** — один раз на кожному пристрої. Без Диска дані лише на пристрої:
   раз на місяць застосунок нагадає зберегти копію.

Подивитися без своїх даних: **⚙ → Демодані** (вигаданий 5″ самозбір на Walksnail, BNF Meteor75, шолом Cobra X,
батареї й польоти). Свій стартовий набір — **⚙ → Резервна копія → Імпорт** файлу `starter.json`.

## Можливості

- **Дрони** (і наземка окремою групою): самозбір чи BNF, шолом, пульт; слоти деталей за типом + свої
  (мотори — чотири окремі слоти). Готовий дрон чи шолом можна прив’язати до позиції замовлення.
  «Замінити» ставить деталь зі складу, зняту — на склад чи «зламана» з причиною; історія у дрона й обох деталей.
  Нотатки з фото, конфіги (`diff all` / dump) з датами — з розбором (прошивка, плата, приймач, мотори, GPS,
  craft_name) і «Оновити прошивку польотника» одним дотиком, фото дрона, вартість = деталі з долею доставки,
  «Скопіювати збірку» — текстом з прошивками.
- **Склад:** деталі зі статусами (на складі / на дроні / зламана / продано), прошивка з історією «X → Y» і підказкою «є новіша» (останній
  реліз Betaflight / INAV / ExpressLRS / EdgeTX на GitHub, раз на добу);
  розхідники кількістю з порогом «мало»; замовлення (магазин, дата, грн чи $ за курсом НБУ, позиції,
  доставка пропорційно ціні) — позиції одразу на склад. «Вкладено в хобі» мінус продане.
  «Хочу купити»: назва, посилання, орієнтовна ціна, для якого дрона — одним дотиком у чернетку замовлення.
- **Батареї:** номер, S, мАг, C, роз’єм, «+ цикл» із напругою й IR (графік за циклами, підсвітка банки, що здає), стан; плашка, якщо батарея
  «заряджена» довше N днів (3, змінюється в ⚙); «Друк наклейок» з номером і QR — камера телефона
  відкриває застосунок одразу на «+ цикл» цієї батареї.
- **Польоти:** дата, місце, дрон, батареї з хвилинами, тип, падіння; кожна батарея отримує цикл, дрон — наліт.
  «Перед польотом»: вітер на 10/80/120 м, пориви, опади, температура (Open-Meteo) й індекс Kp (NOAA) з вердиктом
  «можна / обережно / краще не літати» за вказаними порогами; чекліст, галочки якого скидаються щодня.
- **Експорт у Марнотрат** (⚙ → Дані): замовлення за період — файл для «Резервна копія → Додати до наявних»
  у [Марнотраті](https://github.com/VitaliyLobko/marnotrat); повторний імпорт не дублює.
  Статистика: польоти, наліт за місяцями й дронами, ціна хвилини польоту, витрати на зламане.

## Будова

Без збирання й залежностей: `index.html` + модулі в `js/`, GitHub Pages віддає як є.

| Файл | Що робить |
|---|---|
| `js/app.js` | екрани, форми, логіка |
| `js/db.js` | IndexedDB: drones, items, orders, batteries, flights, wishes, photos, prefs |
| `js/sync.js`, `js/google-token.js`, `js/config.js` | Google Диск, спільний вхід |
| `js/ui.js`, `js/photos.js` | елементи інтерфейсу, фото |
| `js/i18n.js`, `js/ru.js` | мова, російський словник |
| `js/usd.js`, `js/usd-rates.js` | курс долара НБУ |
| `js/fcconfig.js` | розбір конфігу Betaflight / INAV |
| `js/vendor/qrcode.js` | генератор QR (Kazuhiko Arase, MIT) |
| `js/weather.js` | погода Open-Meteo, Kp NOAA, вердикт перед польотом |
| `js/releases.js` | останні релізи прошивок з GitHub |
| `js/changelog.js` | «Що нового» |
| `sw.js`, `version.js` | офлайн-кеш і оновлення (версію піднімати з кожним релізом) |
| `demo.json`, `starter.json` | демодані й стартовий набір |

## Приватність і ліцензія

Сервера немає: дані — у браузері й на **вашому** Google Диску. Content Security Policy в `index.html`
дозволяє звертатися лише до GitHub Pages, Google, НБУ (курс долара), Open-Meteo (погода — лише координати місця),
NOAA (індекс Kp) й GitHub (версії прошивок). Ліцензія — [MIT](LICENSE).
